# Análisis de Valgo Dinámico en Sentadilla Bipodal (DKV Screening Tool)

Herramienta web bioinstrumental estática para la detección y cuantificación del Valgo Dinámico de Rodilla (DKV) mediante visión por computadora en tiempo real.

- **Asignatura:** Análisis Bioinstrumental del Movimiento Humano
- **Institución:** Departamento de Kinesiología, Facultad de Medicina, Universidad de Chile.

## Variables Bioinstrumentales
1. **FPPA (Frontal Plane Projection Angle):** Ángulo de desviación en el plano frontal entre la línea espina ilíaca/cadera-rodilla y rodilla-tobillo.
2. **Ratio Rodilla/Tobillo:** Desplazamiento medial de la rodilla normalizado respecto al ancho de la base bipodal.

## Uso
1. Colocar el dispositivo frente al participante en plano frontal (a la altura de las rodillas/pelvis).
2. Presionar **Iniciar Cámara**.
3. Realizar la sentadilla bipodal. El sistema detecta el nadir de flexión y registra el pico de valgo automáticamente.
